# Security Policy

## Supported versions

Hydra Toon has not made its first release. Security fixes currently target
the `main` branch; no released version is supported yet. This policy will be
updated when release support is established.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/animu-sphere/hydra-toon/security/advisories/new)
to share suspected vulnerabilities. Include steps to reproduce, the affected
revision, potential impact and a suggested fix if you have one. Remove secrets
and other people's private information from reports.

If private reporting is unavailable, open an issue requesting a private
contact channel **without disclosing the vulnerability or reproduction
details**. Do not use a public issue or pull request to disclose a
vulnerability. Maintainers will review reports and coordinate any disclosure
after a fix is available.
