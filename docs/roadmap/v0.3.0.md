# v0.3.0 — avatar animation fast path

The milestone that makes a continuously changing avatar the renderer's
first-class workload, and so `hydra-toon`'s most important one: a renderer
for continuously moving avatars rather than a general Hydra renderer
([design policy §2](../design/DESIGN_POLICY.md#2-core-concept), §11–§14).

**Done when**, measured in ordinary avatar motion, a pose, morph, expression
or camera change needs no scene rebuild, no pipeline rebuild and no full
geometry upload, and the telemetry below shows it in a report.

## Expression, look-at and camera fast paths

Connect the host's facial-expression, viseme and blink input to evaluated
renderer overrides, using the source owner's expression semantics rather
than defining them here. Verify ordinary avatar expression motion in the
dedicated viewport, including mapped inbetween weights and material values.
Verify external look-at evaluation through the joint/weight small-buffer
route without Hydra's full scene sync, with the same separation from
structural state. The renderer receives evaluated results; it does not
link a format repository's evaluator.

The external host consumes `usd-motion-plugins`' `MotionPose`, evaluates its
rig and expressions, and supplies renderer values through the late input
boundary
([integration scope §4](../design/INTEGRATION_SCOPE_POLICY.md#4-dependency-rules)).
Verify a new source-produced sample arriving after scene evaluation and draw
extraction on a representative avatar, with the owner's mapping diagnostics.

## Producer-to-display latency evidence

Use producer timestamps, explicitly mapped to the host's monotonic clock,
to report source-produced motion, expression and gaze sample ages through
buffer write, submit and presentation. Extend the API-return endpoint with
display instrumentation to establish when the sample reached the display
([design policy §23–§24](../design/DESIGN_POLICY.md#23-performance-kpis)).
USD time selection is not a sensor-production timestamp, and presentation
API return is not scanout. Keep those distinctions in the evidence.

## Fast and slow state kept apart

Extend the fast/slow separation evidence to the external host's ordinary
avatar expressions and gaze. A fast change never dirties slow state
([design policy §14](../design/DESIGN_POLICY.md#14-dirty-propagation)); the
telemetry is how this milestone shows it.
