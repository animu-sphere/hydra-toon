# v0.8.0 — Host integration and GPU handoff

Unfinished work of the current milestone; [the index](README.md) owns the
sequence. Deliver the reusable RGBA product to a host application on the GPU,
without per-frame CPU readback, under the [GPU handoff policy](../design/GPU_HANDOFF_POLICY.md)
and the logical contract of [render output policy §7](../design/RENDER_OUTPUT_POLICY.md#7-gpu-texture-handoff).

## Work

- Cut v0.8.0 through the [release gate](../releases/README.md#release-gate)
  and [release steps](../releases/README.md#how-a-release-is-cut).

## Outside this milestone

A WebGPU handoff, cross-process and cross-API sharing, Hgi interop and a
zero-copy `hdToon` AOV, other devices and Linux
([policy §12](../design/GPU_HANDOFF_POLICY.md#12-outside-this-policy)).
Actual display latency stays the separate measurement task in
[later.md](later.md#not-yet-in-a-milestone).

## Done when

One foreground product reaches an intended host without CPU readback: the
reference consumer matches the readback composite exactly through resize,
held slots, several consumers and capture, the Tessera host's frames are
checked against it, and the readback fallback is measured beside the
handoff.
