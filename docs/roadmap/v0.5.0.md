# v0.5.0 — Reusable RGBA output and compositing

Remaining work on Vulkan. The contracts belong to the
[render output policy](../design/RENDER_OUTPUT_POLICY.md) and
[material policy](../design/MATERIAL_POLICY.md); implemented behaviour and
its limitations belong to the [capability matrix](../reference/CAPABILITY_MATRIX.md).

## Reusable RGBA output

- Preserve surface, outline, Mask and Blend alpha through MSAA resolve,
  including partial silhouette coverage and alpha-to-coverage.
- Carry the offscreen colour space, transfer and alpha convention through
  each remaining consumer boundary between scene-linear foreground and
  encoded output.
- Validate host display/export consumers of the premultiplied linear Hydra
  colour AOV, converting at each boundary requiring another convention;
  viewport foreground PNG export alone does not establish those host paths.

## Bounded validation

- Use a small redistributable fixture set spanning MToon, MMD and
  PreviewSurface. Together it must exercise opaque surfaces, outlines,
  Mask, Blend, transparent hair, emission and normal maps, with MMD self-shadow
  included on its receiving surfaces.
- Check the same transparent RGBA product over white, black, checkerboard
  and an arbitrary image. Check silhouette, outline, Mask and MSAA edges
  visually and against expected source-over composites; background selection
  must not change the foreground product.
- Track remaining external tangent comparison in one validation issue with a
  named small asset set and a time budget fixed before capture. Check authored
  and generated frames, a mirrored seam and deformation. If it finds no visible
  defect in the implemented path, record unverified cases as known limitations
  in a report and the capability matrix and defer further comparison beyond
  this release. Apply the
  [reference comparison stop rule](../design/MATERIAL_POLICY.md#121-reference-comparison-and-stop-rule).

## Non-goals

- Pixel-identical Storm output, broader reference suites as a milestone
  deliverable, specular-workflow coverage, arbitrary USD material graphs,
  IBL/environment reflections or MaterialX/glTF PBR fidelity.
- Shared multi-material lighting/shadow resources, WebGPU, GPU texture handoff
  and host integration; see the [later milestones](later.md).
- Exposure, tone mapping, HDR, ground/contact/drop shadows, shadow catchers
  or a transparent native window.

## Done when

The renderer produces background-independent premultiplied RGBA, preserves
alpha through Hydra AOV/readback, and the viewport composites that product.
The bounded fixture set shows no conspicuous silhouette, outline, Mask,
Blend or MSAA edge defects over the four test backgrounds, and the public
output contract agrees with the implementation. Reports document accepted
differences and unverified tangent cases. Storm equivalence is not a release
condition.
