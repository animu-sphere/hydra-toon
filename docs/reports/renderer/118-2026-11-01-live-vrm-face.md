# Live VRM expressions and gaze in the viewport

Date: 2026-11-01. Windows x64/MSVC Release, OpenUSD 26.08, Vulkan, NVIDIA RTX
A5000. A local `avatarVrmSession` build of the runtime after its 0.2.0 release,
which selects expressions and LookAt. Third-party avatars, clips and captured
images remain local and ignored.

## Data flow

`toon-viewport-vrm --vrm-face` selects expressions and LookAt in the runtime's
[native VRM session](https://github.com/animu-sphere/usd-avatar-runtime/blob/main/docs/architecture/VRM_SESSION.md).
The host generates the input only: a rolling wave of expression weights and a gaze
point circling in front of the head, both following the runtime's clock so that a
reset replays them. The owner resolves them in the session. The renderer reads the
resulting retained snapshots under the runtime's
[consumer contract](https://github.com/animu-sphere/usd-avatar-runtime/blob/main/docs/contracts/EVALUATED_STATE.md#4-consumer-contract),
through the existing target matching and `AvatarStateAdapter`. No evaluation, USD
authoring or per-frame Hydra sync was added.

## Evidence

`toon-vrm-runtime-resident`, with VRMA_01, compares cached and uncached runs of the
face over 120 ticks in each of two reset generations, and a run without it:

| Avatar | Expressions | Morph targets | Material inputs | Result |
| --- | --- | --- | --- | --- |
| AliciaSolid (VRM 0.x) | 17 | 46 | 0 | passed |
| VRM1 Constraint Twist Sample (VRM 1.0) | 18 | 98 | 0 | passed |
| Seed-san (VRM 1.0) | | | | refused: `VRM_SPRING_BINDING_SCALE`, the existing scaled spring limit |

For each passing avatar, every morph target matched a resident slot, resident morph
weights changed only with the face, skin palettes differed from the run without it,
cached and uncached streams agreed exactly, the last tick replayed exactly after
reset, and stop restored the authored morphs and materials.

AliciaSolid was drawn for 150 presented frames at 1000x1000 and vsync, with and
without the face: 150 ticks, zero mismatches and refusals, and one Hydra sync. All
150 late reads applied. After the first frame, static uploads were zero; with the
face, morph weight uploads were 517, and zero without it. Captures of the last frame
show the closed eyes and open mouth of the generated weights only with the face. The
agent that made this change reviewed those two captures; no person has accepted them, and
pixels were not compared numerically.

## Limits

Neither passing avatar's expressions bind a material, so a resident material override
from a real avatar is not measured here. The input is generated, not captured. The
eye palette difference is measured with the face as a whole, not separately from
expression weights, and gaze was not checked visually. Windows only. Node constraints
are not evaluated, and real-avatar Hydra/direct parity remains open.
